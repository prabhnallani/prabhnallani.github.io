AI agents · design and prototype

Camera metadata mapping agent

Every vendor names the same field differently. An LLM workflow profiles each field, retrieves vendor docs (RAG), and writes a mapping as a program in a restricted DSL. Code guardrails run it on real samples, an LLM judge can only raise doubts, and a human approves. Production runs with no model call.

AI agents · design and prototype

Pipeline triage agent

When an encode job fails, the pipeline gathers logs and metrics, searches the runbook with BM25, and makes one structured triage call. A bounded code agent with read-only tools then finds the regression and submits a fix that a test runner must prove red, then green, before a draft PR opens.
